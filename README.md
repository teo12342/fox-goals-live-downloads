# Fox Goals live public downloads

Only public CurseForge author download and project counts, updated automatically every 15 minutes by GitHub Actions. No Fox Goals private data is stored here. Data source: https://www.curseforge.com/members/fox_studios_by_teolm30/projects. This repo intentionally fails a refresh rather than fabricating a download count. The endpoint is served at `https://teo12342.github.io/fox-goals-live-downloads/metrics.json` once Pages is enabled.
